# Reporting Security Issues

At Synthesia, we take security seriously and are committed to maintaining the highest standards of security for our users. If you believe you have found a security vulnerability, we encourage you to report it to us as soon as possible.

Please report any security issues in this repo to our Vulnerability Disclosure and Reward Program by emailing security-reports@synthesia.io, where you report will be triaged appropriately.

Please do not open GitHub issues or pull requests. This makes the problem immediately visible to everyone, including malicious actors.

We appreciate your help in making our platform more secure and welcome any feedback or concerns that you may have regarding the security of our platform. Together, we can ensure that our users can continue to enjoy the benefits of Synthesia with peace of mind.
